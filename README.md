# Portfolio Website

A modern, responsive personal portfolio website built with vanilla HTML, CSS, and JavaScript, powered by Vite.

## Features

- **Modern Design**: Dark mode aesthetic with glassmorphism effects and vibrant accent colors.
- **Responsive**: Fully responsive layout that works on all device sizes.
- **Performance**: High-performance static site with critical CSS for fast loading.
- **Theme Toggle**: Light and Dark mode support with persistent preference.

## Tech Stack

- **Build Tool**: [Vite](https://vitejs.dev/)
- **Languages**: HTML5, CSS3 (Variables, Flexbox, Grid), JavaScript (ES Modules)
- **Icons**: SVG Icons (Feather Icons style)
- **Fonts**: [Inter](https://fonts.google.com/specimen/Inter)

## Getting Started

### Prerequisites

- Node.js (v14 or higher)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```bash
   cd portfolio_site
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Development

Start the development server:

```bash
npm run dev
```

### Build

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Project Structure

- `index.html`: Main entry point.
- `project.html`: Project detail page template.
- `src/style.css`: Global styles, variables, and animations.
- `src/main.js`: Main application logic (routing, theme toggle, animations).
