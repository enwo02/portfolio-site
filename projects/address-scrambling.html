Hardware Address Scrambling

Verilog Hardware Security Research ETH IIS

During my semester project at ETH Zürich's IIS Lab, I worked on designing a hardware address scrambling unit. The novel architecture improved memory access efficiency and security against side-channel attacks. This work contributed to a published research paper on secure hardware design.

Key Features

  • Enhanced Security
  • Efficient Memory Access
  • Side-channel Protection
