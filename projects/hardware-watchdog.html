Implementation of a hardware watchdog

SystemVerilog RISC-V FPGA Hardware Verification

Project Overview

This project extends the CROC SoC, a lightweight open-source RISC-V SoC developed at ETH Zürich, with a hardware watchdog. To improve system robustness during development and testing, we designed and integrated a single-stage hardware watchdog that detects processor stalls or bus deadlocks and triggers a chip-wide reset.

Key Features

  • Robust Fault Detection: Detects stalls and deadlocks to ensure system reliability.
  • System-Wide Reset: Automatically triggers a reset pulse to return the SoC to a known-good state.
  • OBI Wrapper: Fully integrated with an OBI-protocol wrapper for memory-mapped access.
  • Configurable: Features a configurable timeout and kick register control.

Results & Impact

The implementation was rigorous, passing all 32 randomized test cases and RTL simulations. The physical design passed DRC and LVS checks with zero violations and minimal area overhead (~1.1% of the core area).

  • Area Cost: Extremely lightweight footprint (~8582 µm² with wrapper).
  • Power Impact: Negligible power consumption impact.
